# Accelerator Program

This repository contains the learning work completed during the Accelerator Program at college, organized in the same folder structure used during training.

## Learning Track

### Daily Python Practice: Day 1 to Day 13
- `DAY1` to `DAY13` — daily Python practice and coding exercises

### Daily SQL Practice: Day 13 to Day 27
- `DAY14` to `DAY27` — daily SQL practice, queries, revision, and database exercises
- `SQL/` — SQL notes, concepts, and practice files

## Repository Structure

- `DAY1` to `DAY27` — daily learning tasks
- `Data_modelling/` — data modelling exercises, project files, and datasets
- `Machine Learning_DeepLearning/` — ML and DL problems, scripts, and model outputs
- `Numpy/` — NumPy practice
- `Pandas/` — Pandas practice
- `Material for learning/` — study notes, PDFs, screenshots, and learning resources
- `Syllabus Weekly/` — weekly syllabus and study materials
- `ML_DL_Revision_Problem1_to_Problem16.md` — ML/DL revision summary
- `SQL_Revision_Day14_to_Day17.md` — SQL revision notes
- `SQL_Revision_Day24_to_Day27.md` — SQL revision notes

## Purpose

This repository is a complete archive of the practical learning done in:

- Python programming
- SQL and database practice
- NumPy and Pandas
- Data modelling
- Machine learning and deep learning
- Revision and assignment-based learning

## Notes

- The original structure has been preserved for easier review and navigation.
- The repository is organized day-wise and topic-wise to follow the learning flow.
- `Capstones` and `TESTS` folders have been removed to keep the project focused on core learning work.
