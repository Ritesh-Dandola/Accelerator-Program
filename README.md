# Accelerator Program

This repository contains the code, exercises, notes, and project work completed during the Accelerator Program.

The folder structure has been preserved as originally organized, so learners can follow the curriculum in the same order and format they used during training.

## Repository Structure

- `DAY1` to `DAY27` — daily Python practice and coding exercises
- `Capstones/` — capstone project files
- `Data_modelling/` — data modelling exercises, projects, and JSON datasets
- `Machine Learning_DeepLearning/` — ML and DL problems, scripts, and model outputs
- `Numpy/` — NumPy-based learning tasks
- `Pandas/` — Pandas-based learning tasks
- `SQL/` — SQL concepts and practice files
- `Material for learning/` — notes, PDFs, screenshots, and learning resources
- `Syllabus Weekly/` — weekly syllabus and learning materials
- `TESTS/` — test and evaluation-related files

## Purpose

This repository serves as a learning archive for:

- Python programming
- SQL and database concepts
- NumPy and Pandas
- Data modelling
- Machine learning and deep learning
- Capstone project work

## Notes

- The original directory hierarchy is maintained for easier navigation and review.
- You can open folders in order to revisit daily learning tasks and projects.
